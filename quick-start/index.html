    Quick start

    Import Specular Differentiation

    Import specular and check the installed package version.

    import specular

print("specular version:", specular.__version__)

    Compute a specular derivative

    Define the ReLU function and evaluate its specular derivative at the kink x = 0. The result is \(\sqrt{2}-1\), approximately 0.41421356237309503.

    def relu(x: float) -> float:
    """Return the rectified linear unit."""
    return max(x, 0.0)


value = specular.derivative(relu, x=0.0)
print("ReLU derivative at 0:", value)

    Backends

    Inspect the backends

    get_backend() returns the backend selected for the current execution context. available_backends() returns the installed backends that can be selected. NumPy is the default.

    available = specular.available_backends()
print("current backend:", specular.get_backend())
print("available backends:", available)

    Install an optional backend

    NumPy is included in the standard installation. To run the optional Numba examples below, install the Numba extra:

    pip install "specular-differentiation[numba]"

    Select a backend persistently

    set_backend() changes the selected backend until it is changed again in the current execution context. A try/finally block makes the restoration explicit.

    specular.set_backend("numba")
try:
    print("selected backend:", specular.get_backend())
    print("ReLU derivative at 0:", specular.derivative(relu, x=0.0))
finally:
    specular.set_backend("numpy")

print("restored backend:", specular.get_backend())

    Select a backend temporarily

    use_backend() limits the selection to a with block and restores the previous backend automatically when the block ends.

    with specular.use_backend("numba"):
    print("inside context:", specular.get_backend())
    print("ReLU derivative at 0:", specular.derivative(relu, x=0.0))

print("after context:", specular.get_backend())
